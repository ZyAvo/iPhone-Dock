🔔 Clés des rappels des Pronos

À faire une seule fois, sur ton ordinateur. Les clés sont créées dans cette page (rien n'est envoyé nulle part) : tu les copies dans les secrets GitHub et dans Apps Script, puis tu fermes la page. Elles ne sont gardées nulle part ici.

Où les mettre
  1. GitHub › ton dépôt › Settings › Secrets and variables › Actions › New repository secret : un secret par clé, avec exactement ces noms : PUSH_PUBLIC, PUSH_PRIVE, PRONOS_CLE.
  2. Apps Script (projet des Pronos) › ⚙︎ Paramètres du projet › Propriétés du script › Ajouter une propriété : nom CLE_TACHE, valeur = la même que PRONOS_CLE. Enregistrer.
  3. GitHub › Actions › Rappels des pronos › Run workflow (une fois) : la clé publique est publiée, le dock la reçoit à la mise en ligne suivante (un quart d'heure environ).

Ne recrée pas les clés plus tard sans raison : les téléphones déjà abonnés devraient réactiver leurs rappels.
